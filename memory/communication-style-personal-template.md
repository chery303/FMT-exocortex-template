## Как это работает

- **S0 (платформа)** - базовые правила для всех. Ты их не видишь, агент загружает автоматически.
- **S2 (`communication-style-personal.md`, твоя копия этого образца)** - твои личные правила. Агент загружает при каждой сессии, если файл существует и не пуст.
- S0 нельзя отменить. S2 добавляет или ужесточает.
- Чтобы обновить - отредактируй свою копию (`communication-style-personal.md`) и сохрани. Этот файл (`-template.md`) трогать не нужно - он только образец.
